# 🚀 Zenith - Analytics Dashboard Platform

Professional SaaS analytics dashboard for real-time data visualization and insights.

## What's Built

✅ **Full-stack application**
- Node.js/Express backend with PostgreSQL
- React frontend with Recharts visualizations
- 10+ database tables for complex analytics
- 20+ API endpoints
- Real-time WebSocket infrastructure
- JWT authentication

✅ **Core Features**
- User registration & login
- Dashboard creation & management
- Drag & drop widget builder
- Multiple chart types (line, bar, pie, gauge)
- Real-time data updates
- Team collaboration ready
- Responsive UI

✅ **Production Ready**
- Clean architecture
- Error handling
- Security best practices
- Scalable design

---

## Get Started (10 min)

```bash
# 1. Database
createdb zenith
psql -d zenith < zenith/backend/config/schema.sql

# 2. Backend (Terminal 1)
cd zenith/backend
npm install && npm run dev

# 3. Frontend (Terminal 2)
cd zenith/frontend
npm install && npm run dev

# 4. Open
http://localhost:5173
```
